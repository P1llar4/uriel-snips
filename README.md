# Uriel Snips

Uriel Snips is the standalone English writing toolkit for Uriel authors. It
provides Uriel, AI-session, and Markdown snippets for characters, scenes,
chapters, Codex links, relationships, timelines, revision, and writing
sessions.

The catalog generator expands the prompt-defined toolkits into 332 validated
templates across AI prompts, characters, scenes, manuscript structure,
worldbuilding, lore, timelines, relationships, poetry, revision, plot,
research, publishing, symbolism, mythic writing, and author workflow.

Run `pnpm validate:snippets` after changing the prompt catalog or snippet
assets. Prefixes are scoped by language so the same authoring shortcut can be
used naturally in Uriel and AI-session documents.

Install dependencies, run `pnpm build`, and press F5 in VS Code to launch the
extension host. The same assets are bundled into Uriel Studio by the unified
platform repository.
