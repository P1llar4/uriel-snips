# Uriel Snips

Uriel Snips is the standalone English writing toolkit for Uriel authors. It
provides Uriel, AI-session, and Markdown snippets for characters, scenes,
chapters, Codex links, relationships, timelines, revision, and writing
sessions.

Install dependencies, run `pnpm build`, and press F5 in VS Code to launch the
extension host. The same assets are bundled into Uriel Studio by the unified
platform repository.
